# IELTS vocabulary

### 雅思词汇真经单词音频

[**打开网站，开始听单词 →**](https://daix74991-jpg.github.io/ielts-vocabulary/)

[反馈问题](https://github.com/daix74991-jpg/ielts-vocabulary/issues)

无需注册或安装。手机、平板和电脑浏览器打开即可使用。

## 功能

- 按《雅思词汇真经》22 个单元分类，按书中顺序显示 3,674 个词条。
- 点击单词行展开／遮住中文释义；使用英音、美音按钮听读。
- 可一键显示或遮住全部中文。释义显示用户提供 PDF 中的原书片段，按章节加载，避免扫描识别造成中文错字。
- 点击星标加入独立单词本，支持英美发音、重复、顺序播放和中文遮挡。收藏保存在当前浏览器，刷新后保留；不会跨设备同步，清理网站数据会清除收藏。
- 每词可重复 1、2、3、5、10 次，或无限循环。
- 支持顺序播放、单元循环、播放间隔、语速、暂停和停止。
- 22 个章节使用不同主题，简约暖色界面，适配手机屏幕。
- 只播放词条，不播放例句。页面提供分享按钮，方便把链接发给朋友。

## 使用方法

1. 在目录选择单元；手机上可以左右滑动目录。
2. 选择发音、每词重复次数和间隔。
3. 点击“英音”或“美音”听读，或点击“顺序播放”听整个单元。
4. 点击单词查看中文；点击 ☆ 收藏，在“我的单词本”集中复习。

手机首次播放需要点一下按钮。锁屏、后台和省电模式可能暂停网页音频；保持页面在前台可获得更稳定的连续播放体验。

## 词表与音频

词表根据用户提供的 PDF 索引、目录、页码和正文页脚词表整理，14 处识别异常已对原页修正。已核对低置信度拼写和 278 个词条页的页脚顺序。

音频来自有道在线词典，需要联网，**并非出版社配套录音**。2026-09-28 抽查覆盖 22 个单元首、中、末词及短语，共 138 条英美音频链接，均返回音频；这不代表全部音频已逐条人工听辨。多音词默认读法受词典服务影响。如发现词条、顺序或读音问题，欢迎提交 Issue。

这是个人学习工具，与原书作者、出版社及 IELTS 官方无关联。仓库不包含完整原书 PDF；中文释义为用户提供 PDF 中对应词条的释义裁片，不包含例句。

## 本地运行

GitHub 仓库的 `index.html` 位于根目录，下载后可用任意静态 HTTP 服务运行；开发工作区的网页文件位于 `dist/`。无须安装项目依赖。

```sh
node --check app.js
node test-player.cjs
```

修改网页文件后提交到 `main`，GitHub Pages 会自动更新网站。网站通过 HTTPS 提供服务。
